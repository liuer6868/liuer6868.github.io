欢迎来到我的博客！这是第一篇文章。

## 开始写博客

用下面这条命令新建一篇文章：

```bash
npx hexo new "我的第一篇文章"
```

文章会生成在 `source/_posts/` 目录下，用 Markdown 编写。

## 常用命令

```bash
npx hexo clean     # 清理缓存和已生成的静态文件
npx hexo generate  # 生成静态文件到 public/
npx hexo server    # 本地预览，默认 http://localhost:4000
npx hexo deploy    # 部署到 GitHub Pages
```

## 支持 Markdown 语法

- **加粗**、*斜体*、`行内代码`
- [链接](https://hexo.io)
- 表格、引用、代码块

> 引用示例：不积跬步，无以至千里。
